# ACAS -- COBOL to Python 3.12 migration of the batch posting cycle.
# THE SHIPPED RUNTIME SET: a flat, hash-verified mirror of pyproject.toml's
# [project].dependencies, for environments without a build backend and for
# container builds that must install under --require-hashes.
#
#     pip install --require-hashes -r requirements.txt
#
# Every requirement carries a --hash for every artifact of its pinned version
# that CPython 3.12 can install, read from the package index metadata rather than
# transcribed by hand, so a substituted index cannot serve different bytes under
# the same version number. requirements-harness.txt and requirements-dev.txt
# mirror the other two dependency sets; the three sets are pairwise disjoint, and
# a version that differs from pyproject.toml is a defect.
#
# DO NOT UPGRADE, downgrade or "check for newer". A driver or runtime change can
# move a stored penny, and the only acceptable proof of equivalence is an empty
# scenario diff against the compiled COBOL oracle. The build backend is
# deliberately absent: it is a BUILD requirement the cycle never imports, and
# requirements-dev.txt carries its hashed entry instead.
